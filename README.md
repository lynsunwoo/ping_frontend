# Ping Frontend

Ping 프로젝트의 프론트엔드 배포용 저장소입니다.

## Overview
본 프로젝트는 팀 프로젝트로 시작되었으며,  
초기 개발 및 협업은 별도의 팀 저장소에서 진행되었습니다.

이후 배포 및 운영 구조에 맞게  
프론트엔드만 분리하여 이 저장소에서 관리했습니다.

React 기반으로 사용자 화면과 인터랙션을 구현했으며,  
Cloudtype 환경에서 프론트엔드 배포를 진행했습니다.

## Tech Stack
- React
- JavaScript
- SCSS
- Axios

## Main Features
- 메인 / 상세 / 아카이브 페이지 UI 구현
- 핀 위치 기반 질문 인터페이스
- 카테고리별 검색 및 필터 기능
- 관리자 기능 관련 UI 및 API 연동
